## 📖 核心概念

### 什么是抢权配债？

可转债发行时，老股东有**优先配售权**。在**股权登记日**收盘前买入正股，获得配债权后卖出正股，再在转债上市时卖出转债，赚取"转债打新收益"覆盖"正股买卖价差"的超额收益。

### 核心公式

```
每手转债需持股 = CEIL(1000 / 每股配债额 / 100) × 100
安全垫（%）  = (万元市值配债收益 / 10000) × 100%
盈亏平衡点    = 安全垫（%）
```

**解读**：安全垫 = 正股最多跌多少百分比，策略整体才不赚钱。安全垫越高，策略越安全。

## 📊 输入参数说明

| 参数 | 说明 | 获取方式 |
|------|------|----------|
| 正股代码 | 如 `601899` | 自行填写 |
| 正股名称 | 如 `紫金矿业` | 自行填写 |
| 正股当前价 | 元/股 | 行情软件实时查看 |
| 每股配债额 | 每张转债面值对应配几元 | **发行公告书**里查"每股配售金额" |
| 股权登记日 | T日 | 发行公告书 |
| 预估上市溢价率 | 默认 20% | 参考同类转债，保守取 15~25% |
| 总资金 | 默认 10 万元 | 自行设定 |

### 如何查"每股配债额"？

在巨潮资讯网或上交所/深交所官网搜索《可转债发行公告》，里面有一张表：

```
每股配售额（元面值）= 本次发行规模(元) / 股权登记日总股本(股)
```

公告原文通常写："每股配售 X.XXX 元面值" 或 "每手(1000元)需持股 YYY 股"。

## ⚠️ 风险提示

1. **正股下跌风险**：抢权资金在股权登记日后集中卖出，正股往往承压下跌
2. **转债溢价率不及预期**：如遇市场调整，转债上市溢价率可能远低于预估
3. **配债缴款资金占用**：获配后需在申购日缴款，资金被占用 2~4 周
4. **大盘系统性风险**：市场暴跌时，安全垫再高也可能失效

## 🛠️ 可编程调用（Python）

```python
from bond_calc import BondIssue, BondStrategyCalculator

data = BondIssue(
    stock_code="601899",
    stock_name="紫金矿业",
    record_date="2026-07-01",
    stock_price=15.20,
    allotment_per_share=1.2345,
    bond_est_premium=20.0,
)

calc = BondStrategyCalculator(data)
print(calc.full_report(total_capital=100000.0))

# 获取结构化数据
pos = calc.optimal_position(100000.0)
print(f"安全垫: {pos['safety_cushion_pct']:.2f}%")
```
